## Бизнес-правила и их реализация
### Бизнес-правило: Клиент должен быть старше 18 лет для самостоятельного оформления бронирования.

**Реализация:** 
Триггер проверяет возраст клиента при добавлении или изменении записи в таблице Client. Если возраст меньше 18 лет, бронирование запрещается.

```sql
-- Триггерная функция
CREATE OR REPLACE FUNCTION check_client_age()
RETURNS TRIGGER 
LANGUAGE plpgsql
AS $$
BEGIN
    IF AGE(NEW.birth_date) < INTERVAL '18 years' THEN 
        RAISE EXCEPTION 'Клиент младше 18 лет';
    END IF;
    RETURN NEW;
END;
$$;

--  Триггер
CREATE TRIGGER trg_client_age 
BEFORE INSERT OR UPDATE ON Клиент
FOR EACH ROW EXECUTE FUNCTION check_client_age();

```

**Пример**
```
INSERT INTO client (surname, name, patronymic, birth_date, phone, email, passport_data) 
VALUES ('Петров', 'Петр', 'Петрович','2010-05-20', '+79161234567', 'petr@mail.ru', '1234567890');
```

**Результат - ОШИБКА:  Клиент младше 18 лет**


### Бизнес-правило: Дата прибытия транспорта должна быть позже даты отправления
**Реализация: Триггер  проверяет корректность дат транспорта.**

```
Код триггера:

CREATE OR REPLACE FUNCTION check_transport_dates()
RETURNS TRIGGER AS $$
BEGIN
    IF NEW.arrival_date <= NEW.departure_date THEN
        RAISE EXCEPTION 'Дата прибытия должна быть позже даты отправления!';
    END IF;
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_transport_dates
BEFORE INSERT OR UPDATE ON transport
FOR EACH ROW EXECUTE FUNCTION check_transport_dates();
```
**Пример**
```
INSERT INTO transport ( transport_type, carrier_name, departure_date, arrival_date, ticket_price )
VALUES ('Plane',  'Aeroflot', '2024-12-01',   '2024-11-30',  -- Дата прибытия  10000.00 );
```
**Результат - ОШИБКА:  Дата прибытия должна быть позже даты отправления!**

**Бизнес-правило: Общая стоимость бронирования рассчитывается как объединение стоимость тура, проживания и транспорта с учетом количества людей и длительности.**
```
CREATE OR REPLACE FUNCTION calculate_total_cost(tour_id INT, hotel_id INT, transport_id INT) 
RETURNS NUMERIC AS $$

DECLARE
    total NUMERIC;
    tour_duration INT;
    people_count INT;

BEGIN
    SELECT t.duration, b.number_of_people 
    INTO tour_duration, people_count
    FROM tour t
    JOIN booking b ON t.tour_id = b.tour_id
    WHERE t.tour_id = calculate_total_cost.tour_id;

SELECT (t.price + h.accommodation_cost * tour_duration + tr.ticket_price) * people_count
    INTO total
    FROM tour t
    JOIN hotel h ON h.hotel_id = calculate_total_cost.hotel_id
    JOIN transport tr ON tr.transport_id = calculate_total_cost.transport_id
    WHERE t.tour_id = calculate_total_cost.tour_id;

    RETURN total;
END;
$$ LANGUAGE plpgsql;
```

**Бизнес-правило: В бронировании должно участвовать не менее 1 человека.**
Триггерная функция
```
CREATE OR REPLACE FUNCTION check_min_people()
RETURNS TRIGGER AS $$
BEGIN
    IF NEW.number_of_people < 1 THEN
        RAISE EXCEPTION 'Количество человек должно быть не менее 1!';
    END IF;
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;
```
```
Триггер
CREATE TRIGGER trg_check_min_people
BEFORE INSERT OR UPDATE ON booking
FOR EACH ROW EXECUTE FUNCTION check_min_people();
```
Пример
```
INSERT INTO booking (client_id,tour_id,hotel_id,transport_id,number_of_people)
VALUES 
(4,4,4,4,0);
```
**Результат - Количество человек должно быть не менее 1**

### Индексы
**Индекс idx_tour_country**
 Ускоряет поиск туров по стране назначения.

**Индекс idx_booking_client**
Индекс позволяет быстро найти все записи клиента

**Индекс idx_hotel_stars**

Индекс помогает быстро найти все отели с необходимым рейтингом



### Рейтинг используемых объектов базы данных
Таблицы:
booking (Бронирования):
агенты создают, изменяют, отменяют бронирования.
tour (Туры):
поиск туров по стране, цене, датам.
client (Клиенты):
регистрация, авторизация, просмотр истории бронирований
hotel (Отели):
фильтрация по звездам, местоположению.
transport (Транспорт):
поиск по датам и типу транспорта.
